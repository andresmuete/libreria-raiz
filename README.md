# Librería Independiente Raíz

Sitio estático para GitHub Pages.

## Publicación
1. Integre cambios revisados a `main` mediante Pull Request.
2. Abra Settings → Pages.
3. Seleccione Deploy from a branch, rama `main`, carpeta `/(root)`.
4. Espere el despliegue y pruebe la URL indicada por GitHub.

URL típica: `https://USUARIO.github.io/NOMBRE-REPOSITORIO/`. Reemplace los marcadores por datos reales. Use commits como `fix: corregir rutas relativas` y solicite Code Review antes de fusionar.
